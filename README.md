Проект по практическим занятиям «Фронтенд и бэкенд разработка (часть 1 из 2)». За основу взяты HTML, CSS и JavaScript из предоставленных методичек. Примеры последовательно адаптированы под магазин одежды, затем добавлены небольшие самостоятельные доработки. Итог — контрольная работа №1, описанная в практическом занятии №8.

## Страницы

- `index.html` — главная: hero, преимущества, три карточки, aside.
- `catalog.html` — каталог с боковой панелью и сеткой товаров.
- `product.html`, `product-hoodie.html`, `product-jeans.html` — три товара с изображением, описанием, ценой и таблицей характеристик.
- `order.html` — отдельная страница заявки.
- `contacts.html` — контакты и частые вопросы.
- `delivery.html` — условия доставки.
- `sizes.html` — размерная сетка и рекомендации по уходу.

Общие стили — `css/style.css`, обработка формы — `js/main.js`, локальные иллюстрации — `images/`, карта страниц — `sitemap.xml`. Зависимости и сборка не требуются.

## Что добавлено сверх примеров

Две дополнительные страницы (доставка, размеры и уход), отдельные страницы всех трёх товаров, изображения одежды, FAQ на нативных `details/summary`, бейджи «Хит», «Новинка», «Скидка», дополнительный выбор размера и видимое название выбранного товара. Добавлены переносы на узком экране, ссылка перехода к содержимому, состояния клавиатурного фокуса и кнопка возврата наверх. Эти доработки используют обычные HTML/CSS и небольшой JavaScript.

## Запуск и форма

Откройте папку проекта в VS Code, затем `index.html` в браузере. Можно использовать Live Server, если он уже установлен, либо из папки проекта запустить:

```sh
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000`.

Кнопки «Заказать» открывают `dialog`; товар передаётся через `data-product` в скрытое поле. Проверяются имя, email, телефон в формате `+7 (900) 123-45-67`, тема и согласие. Дата, размер и комментарий необязательны. `novalidate` позволяет обработчику самостоятельно вызвать `checkValidity()` и `reportValidity()`, отметить ошибки `aria-invalid`. При успехе форма очищается, диалог закрывается, показывается сообщение.

**Это учебная клиентская форма:** обработчик отменяет отправку через `preventDefault()`, сервер и сохранение заявок не подключены. Используйте тестовые данные. Фильтры каталога — статичная разметка из занятия №6, кнопка применения отключена и подписана; рабочая фильтрация относится к следующей части курса.
