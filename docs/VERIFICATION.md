# Проверки итоговой версии

Проверено в браузере и локальной структурной проверкой 6 октября 2026 года:

- На всех 9 страницах один main и один h1, нет дублирующихся ID.
- Все относительные ссылки, изображения, якоря и aria-describedby указывают на существующие цели.
- Все видимые поля формы имеют связанные label; изображения имеют alt.
- JavaScript проходит `node --check js/main.js`.
- На ширине 390px у всех девяти страниц отсутствует горизонтальное переполнение.
- Главная на ширине 1366px не имеет горизонтального переполнения.
- Заказ толстовки открывает dialog и передаёт правильный товар и тему.
- Пустая форма получает aria-invalid на обязательных полях.
- Корректные тестовые данные показывают сообщение, закрывают dialog и очищают форму.
- Escape закрывает dialog.
- На отдельной странице заявки неверные email/телефон дают typeMismatch/patternMismatch; корректные данные завершают демонстрацию без перехода на другой URL.
- В проверенных сценариях ошибок JavaScript в консоли нет.

Не подключены сервер, оплата, хранение заявок и реальная фильтрация: по методичке эта часть статическая. Полная внешняя проверка HTML валидатором не выполнялась; перечислены конкретные выполненные проверки, а не заявление о сертификации.
