# Подготовка к защите

1. **Структура.** header — шапка, nav — навигация, main — основное содержимое, section — тематический раздел, article — самостоятельная карточка, aside — дополнительные сведения, footer — подвал. h1 один на каждой странице.
2. **Flex и Grid.** Flexbox располагает элементы в одном направлении (меню, внутренности карточки). Grid создаёт сетку карточек; в каталоге `grid-template-areas` задаёт области filters и products, `grid-area` назначает их элементам.
3. **БЭМ.** `product-card` — блок, `product-card__title` — элемент, `product-card--featured` — модификатор. Базовый класс сохраняется вместе с модификатором.
4. **Переменные.** `:root` хранит общие цвета, отступы и радиусы. `var(...)` позволяет менять тему из одного места.
5. **Состояния.** :hover отвечает на указатель, :focus-visible показывает клавиатурный фокус, :disabled — недоступность кнопки, [aria-invalid="true"] — отмеченное ошибочное поле.
6. **Позиционирование.** У карточки relative, бейдж absolute относительно карточки; панель фильтров sticky, ссылка наверх fixed; z-index задаёт порядок перекрытия. dialog использует верхний слой браузера.
7. **Форма.** label связан с контролом через for/id. required задаёт обязательность, type=email проверяет формат почты, pattern — телефона, minlength — имени. novalidate оставляет запуск проверки нашему обработчику.
8. **JavaScript.** querySelectorAll выбирает кнопки, addEventListener подписывает на клик, dataset.product читает товар, showModal открывает диалог. submit отменяет POST, проверяет поля, при ошибке показывает reportValidity, при успехе сбрасывает форму и закрывает окно.
9. **Доступность.** Осмысленные alt, подписи полей, aria-current в меню, подпись dialog, skip-link, видимый фокус, сообщение role=status. Escape закрывает нативный dialog.
10. **Git.** Ветка изолирует этап, коммит сохраняет изменение, PR показывает diff и объединяется в main. Pages публикует статические файлы из основной ветки.
