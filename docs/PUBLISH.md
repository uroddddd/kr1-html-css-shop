# Публикация в GitHub Pages

## Через интерфейс GitHub

1. Войдите в GitHub под аккаунтом `uroddddd`.
2. Создайте отдельный публичный репозиторий `kr1-html-css-shop`. Не добавляйте отдельный README при создании, если будете загружать подготовленную Git-историю.
3. Загрузите содержимое папки проекта в корень репозитория. В корне должны лежать `index.html`, `catalog.html`, `css/`, а не ещё одна вложенная папка `kr1-html-css-shop/`.
4. Откройте Settings → Pages. В разделе Build and deployment выберите Deploy from a branch, ветку `main`, папку `/ (root)` и Save.
5. Дождитесь успешной публикации. GitHub покажет ссылку сайта. Проверьте https://uroddddd.github.io/kr1-html-css-shop/.
6. Откройте пять обязательных страниц, страницу доставки, пару отдельных товаров, модальное окно и форму. Проверьте относительные ссылки и отсутствие ошибок загрузки.
7. После подтверждения публикации замените статус в README на «Опубликовано через GitHub Pages»; снимите аналогичные пометки в карте критериев и журнале проверки.
8. В СДО сдайте https://github.com/uroddddd/kr1-html-css-shop.

## Через Git

Локальная Git-история входит в папку проекта. Посмотреть её:

```bash
git log --oneline
```

После создания пустого репозитория, из папки проекта:

```bash
git remote add origin https://github.com/uroddddd/kr1-html-css-shop.git
git push -u origin main
```

Если `origin` уже настроен, пропустите его добавление и проверьте `git remote -v`. Для HTTPS используйте штатную авторизацию GitHub; пароль аккаунта не подходит для Git push. Не храните токены в коде, README, `.env` или адресе remote.

Затем включите Pages в Settings, как описано выше. Загрузка ZIP целиком не публикует сайт: необходимо загрузить распакованные файлы.

## Если загружаете через Upload files

Перетаскивайте распакованные файлы и папки из проекта. Обычная загрузка файлов через интерфейс создаёт новую историю в GitHub и не переносит локальные коммиты. Сохранение истории лучше выполнить через Git push.

Pull Request не обязателен по заданию: его нужно показать только если он создавался.
